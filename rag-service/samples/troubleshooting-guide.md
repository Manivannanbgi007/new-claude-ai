# ShopTech Device Troubleshooting Guide (fictional sample document)

## Error code E-4012: charger not recognised
Error E-4012 appears when a laptop does not recognise the connected power adapter.
1. Disconnect the adapter for 30 seconds.
2. Try a different power outlet.
3. Only use the original 65W USB-C adapter; third-party adapters below 45W trigger E-4012.
If the error remains, the charging port may be defective, which is covered by the warranty.

## Error code E-2207: display flickering
E-2207 is logged when the display refresh rate cannot be kept stable.
Update the graphics driver and set the refresh rate to 60Hz as a test.

## Bluetooth headphones do not connect
Reset the headphones by holding the power button for 15 seconds until the light flashes blue
and red, then remove the device from your phone's Bluetooth list and pair it again.
